# Homepage partner logo review

The live strip uses only verified local logo files. Existing marks remain in
place; requested marks with verified local assets are added. Missing logos are
not replaced with typed names or invented artwork.

## Inventory

- Original set preserved: 17 marks.
- Requested list: 28 names, including Jack in Jones (already present in the
  original set); 27 unique additions requested.
- Requested marks available locally: Adidas, Reebok, JBL, Sony, and Jack&Jones.
- Unique combined brand set: 44. The current live strip has 21 distinct marks:
  the original 17 plus Adidas, Reebok, JBL, and Sony.
- Requested brands still awaiting a reviewed logo file: 23.
