# Visual Style Notes — Gifting Brief Pre-Production

## Benchmarks (principles only)

- **Quality bar:** Swag / NotReal commercial craft (motion, materials, continuity) — never copy footage, models, or storyboards.  
- **Art direction:** Hustlemad Behance 2023 — colour blocking, merchandise-led polish, editorial type energy — never copy characters/layouts/assets.

## Look

Photoreal-inspired **stylized 3D merch** + **professional adult cartoon** characters in one continuous animated world.  
Signature motion: **sketch line → dimensional product** with fabric, metal, paper, and packaging materials.

## Anti-patterns (blocked for this film)

- Floating UI card explainer look / PowerPoint  
- Flat SVG icons as primary merchandise  
- Fake “successfully sent” confirmation  
- Childish mascot proportions  
- Invented customer logos, prices, or shipping promises
